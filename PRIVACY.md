# Privacy Policy: Shorts Autopilot

_Last updated: 6 October 2026_

Shorts Autopilot is a personal tool used by the owner of this repository to upload
their own videos to their own YouTube channel. It is not offered to other users.

## What it accesses
- It uses Google's YouTube Data API with a single permission,
  `youtube.upload`, granted by the channel owner, to upload videos to that
  owner's channel.
- It does not read, collect or store any data about other YouTube users, viewers,
  comments or subscribers.

## How credentials are stored
- The owner's Google OAuth credentials (client ID, client secret and refresh
  token) are stored as encrypted GitHub Actions secrets in this repository. They
  are used only to upload videos and are never shared with anyone else.

## Data sharing
- No personal data is sold, shared or transferred to third parties.
- Video files are sent only to YouTube. Stock footage is downloaded from free
  stock-video services; no personal data is sent to them.

## Revoking access
The channel owner can revoke access at any time at
https://myaccount.google.com/permissions.

## Use of YouTube
This tool uses YouTube API Services. By using it you agree to the
[YouTube Terms of Service](https://www.youtube.com/t/terms). See also the
[Google Privacy Policy](https://policies.google.com/privacy).

## Contact
Questions about this policy: open an issue on this repository.
