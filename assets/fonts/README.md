# Fonts

`Inter-Regular.otf` and `Inter-SemiBold.otf`: **Inter** by Rasmus Andersson
(https://rsms.me/inter/), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and commercial use.
Used for the text-message bubbles in text-story videos.

Stickman-story videos (all SIL Open Font License 1.1 as well):
- `BebasNeue-Regular.ttf`: **Bebas Neue** by Dharma Type (titles, rule cards).
- `Montserrat-ExtraBold.ttf`, `Montserrat-Black.ttf`: **Montserrat** by Julieta
  Ulanovsky (captions).
- `JetBrainsMono-Bold.ttf`, `JetBrainsMono-Regular.ttf`: **JetBrains Mono** by
  JetBrains (the day / clock counter).
